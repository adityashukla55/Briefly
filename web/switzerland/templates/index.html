Reply letter templates for Switzerland

Ready-made letters in German, with an English explanation.

  • Object to the decision (Einsprache) — Use this if you think the decision is wrong. Send it signed before the deadline, with your reasons and what you want changed.
  • Ask for more time (Fristerstreckung) — Use this if you can’t make the deadline. Send it before the deadline ends.
  • Ask to pay in parts (Ratenzahlung) — Use this if you can’t pay the full amount at once. Offer an amount you can really pay every month.
  • Ask for a new appointment — Use this if you can’t come. Send it before the appointment and add proof if you can (for example a doctor’s note).
  • Object to the debt collection (Rechtsvorschlag) — Use this if you don’t owe the money, or only part of it. Post it to the Betreibungsamt within 10 days after you got the Zahlungsbefehl, best by registered post (Einschreiben). You don’t need to give a reason.
