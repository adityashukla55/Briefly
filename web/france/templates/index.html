Reply letter templates for France

Ready-made letters in French, with an English explanation.

  • Object to the decision (recours gracieux) — Use this if you think the decision is wrong. Send it before the deadline, signed, and keep a copy.
  • Ask for more time (délai supplémentaire) — Use this if you can’t make the deadline. Send it before the deadline ends.
  • Ask to pay in parts (échéancier) — Use this if you can’t pay the full amount at once. Offer an amount you can really pay every month.
  • Ask for a new appointment — Use this if you can’t come. Send it before the appointment and add proof if you can (for example a doctor’s note).
  • Ask to cancel or reduce the debt (remise de dette) — Use this if you must pay money back but your situation is very hard. Explain your income and costs, and add proof.
